# Knowledge Base

Notas de estudio (DDD, SOLID, CQRS, EDA...) pensadas para recuperación híbrida (RRF: embeddings + palabras clave).

## Convenciones

- Una carpeta por tema (`ddd/`, `cqrs/`, `eda/`, `solid/`...), un fichero Markdown por concepto.
- Cada nota empieza con frontmatter YAML: `title`, `topic`, `subtopic`, `tags`, `aliases` (sinónimos/términos en inglés para la búsqueda por palabras clave), `sources`, `created`.
- Secciones con encabezados `##` autocontenidos para que el chunking por sección funcione bien.
- Contenido basado en fuentes citadas, con ejemplos de código y diagramas Mermaid.
